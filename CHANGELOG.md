## 0.1.0 — 2026-08-09

### Features
- Centinel v2 spine — library, #[op] macro, CLI/MCP/HTTP
- **collect**: sitemap discovery, polite collection, and text extraction
- **search**: chunking, SQLite FTS5 index, and BM25 search
- **open**: browsable current/ tree and a config-driven open subcommand
- **progress**: named tracks and byte units, rendered as bars on a terminal
- **models**: pinned GGUF registry with resumable, digest-verified downloads
- **doctor**: report model weights beside the binary probes
- **embed**: local inference via llama.cpp, and the durable vector cache
- **models**: whisper and VAD weights, with readiness reported per gate
- **transcribe**: whisper.cpp in a process of its own
- **youtube**: a channel as a Source, refusal distinguished from absence
- **captions**: derive timestamped transcripts from YouTube json3
- **youtube**: fetch audio for the videos YouTube never captioned
- **render**: reports read as prose on a terminal, JSON in a pipe
- **run**: one command walks the config and collects only what changed
- **source**: list what the store holds, not only what the config declared
- logging init
- default the store to ~/.centinel
- **collect**: fetch the documents a page encloses
- **progress**: a scrolling request log over a pinned tally
- **progress**: the scrolling log covers extract too
- **extract**: a second reader for PDFs the first makes nothing of
- **search**: hybrid retrieval, and no embedding cache
- **op**: Reach replaces local_only, and ops can be cancelled
- **schedule**: cron in a named zone, and the [[schedule]] block
- **journal**: runs/ records every attempt, and run.lock is the lane
- **ops**: schedules, history, and the schedule writer
- **serve**: the scheduler loop, on its own runtime
- **cli**: schedule set with nothing to type
- **check**: see what extraction makes of one link, without keeping it
- **install**: one script installs both binaries, tuned for this host
