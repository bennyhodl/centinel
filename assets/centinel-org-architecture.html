Centinel — Organization Chart & Interactions

Six-agent civic-investigation roster, file-based message passing, operator-in-the-loop control planes

Operator control planes

  • • /chat — agentic Q&A + lifecycle ops via Hermes API
  • • /investigations — create + pause/resume/trigger
  • • /operator-queue — approve/reject/dismiss/snooze
  • • /findings — promote draft → published
  • • centinel-<role> — direct terminal session per profile

Inter-agent message passing

  • • All comms via files in _runtime/{inbox,outbox}/
  • • Frontmatter envelope: id, type, from, to, status
  • • Per-cron --script preloads inbox into context
  • • Operator-queue is just inbox for the human
  • • Approvals → web → inbox file → next agent tick

Editorial firewall (writers)

  • • Data Reporter — sole DB writer + methodology log
  • • Archivist — sole Vault writer (immutable bytes)
  • • Investigator — drafts only, never published
  • • Watch Runner — Findings/raw OK, narrative = draft
  • • Operator — promotes drafts via /findings

Authority & gates

  • • Hermes API key gates X-Hermes-Session-Id
  • • Entity merges require operator approval (via queue)
  • • Watch tunings require operator approval
  • • Editor confirms before destructive CLI ops
  • • Citations mandatory (no source = no claim)

Schedules (defaults, in cron)

  • • investigator-tick — every 4h
  • • watch-runner — every 4h
  • • data-reporter — every 6h
  • • vault-manifest (archivist) — every 15m
  • • sitemap-lint — Mon 03:00
  • • briefings — Mon 09:00 · huddle-rollup — daily 18:00
  • • snooze-sweep — daily 06:00

Web → agent boundaries

  • • Web NEVER originates state — only file writes
  • • /investigations create → atomic .md + register cron
  • • /operator-queue approve → drop inbox + flip status
  • • /chat → Hermes API → real agent loop
  • • Lifecycle CLI = bin/centinel via execFile (30s timeout)
